# 서울 신속통합기획

서울도시공간포털에서 2026-10-02 수집한 230개 구역(추진중 98, 완료 132)의 공개 도시계획·도시계획사업 자료입니다.

사이트: https://cloudmate37.github.io/Seoul_redeveolopment/

- 구역명·주소 검색, 자치구·추진상태 필터
- 구역별 도시계획·도시계획사업·첨부파일 탭
- 도시계획 5,148행, 연결 도시계획사업 603행, 첨부 원본 링크 6,505개
- 전체 상세항목, 추진이력, 고시, 지구단위 구역정보·지침, 공간 연결 근거
- 엑셀 다운로드와 구역별 직접 링크

첨부는 서울시 원본 URL로 연결하며 대용량 첨부 파일을 저장소에 올리지 않습니다. 자료가 원본에 없는 조서 19건은 화면의 수집 누락에서 확인할 수 있습니다. 조서 ID 없이 제공되는 지도 도형은 별도 표시합니다. 지구단위계획 158개 중 91개의 개요 첨부는 원본에서 자료 없음으로 응답했고, 나머지 상세와 도면은 보존합니다. 자료기준일은 사업마다 다르며 수집일과 구분합니다.

구역 경계 전체와 서울시 현황 지도 레이어의 공간 교차로 연결했습니다. 같은 조서·사업이 여러 구역에 나타날 수 있어 엑셀 행 수는 고유 조서·사업 수와 다릅니다. 반복 행의 면적을 그대로 합산하지 마세요.

## 실행 및 배포

패키지 설치 없이 `python3 -m http.server 8765`로 실행합니다. `http://localhost:8765`에서 확인합니다. 구역별 JSON을 요청하므로 파일을 직접 여는 대신 HTTP 서버를 사용합니다.

GitHub Pages의 배포 소스는 `main` 브랜치의 루트(`/`)입니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

`index.html`, `style.css`, `app.js`는 화면, `data/catalog.json`은 검색 목록, `data/districts/*.json`은 구역 상세입니다. 첫 화면에서 전체 상세를 내려받지 않고 선택한 구역만 불러옵니다.

`scripts/build_site.py`는 로컬 수집 결과를 공개 사이트 자료로 변환하며 설치된 Python 표준 라이브러리만 사용합니다. 입력은 로컬 수집 폴더, HTML 템플릿, 엑셀 중간 출력 폴더 순서입니다. 엑셀은 기존 공용 Artifact Tool 내보내기 스크립트로 생성합니다.

원본: https://urban.seoul.go.kr/view/map/main.html
